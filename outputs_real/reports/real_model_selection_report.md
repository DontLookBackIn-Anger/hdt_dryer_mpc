## 一、从数据特征反推：为什么不能“随便套一个模型”？

结合前两步（`r1` 探索 + `r2` 时滞辨识 + `r1b` 表头核对）在真实数据中发现的 5 个硬约束，我们的模型架构与训练范式必须针对性设计：

| 真实数据特征（已验证）                                                                         | 对建模造成的直接挑战                                                               | 本方案的架构级解法                                                                                                                                                               |
| :--------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 强一阶惯性 + 0.01% 量化台阶**$\text{ACF}(1\text{s}) > 0.99$，出口水分最长冻结 41s | 单步预测（$h=1\text{s}$）即使什么都不学也能拿到 $R^2 > 0.98$，极易误判模型好坏 | 锁定**多步预测** `horizons = [1, 15, 30, 60]s`，并以 **Naive Persistence** 为硬下限计算 Skill Score                                                                |
| **2. 跨批次均值漂移**18 批次出口温度均值在 `48.8~50.7℃` 间移动                        | 直接预测绝对值 $\hat{y}(t+h)$ 在新批次上容易产生系统性截距偏移                   | **残差增量预测范式**：所有模型不预测绝对值，而是预测相对当前时刻的变化量 $\Delta\hat{y}(t+h) = \hat{y}(t+h) - y(t)$，再还原 $\hat{y}(t+h) = y(t) + \Delta\hat{y}(t+h)$ |
| **3. 工艺纯滞后约 32–53 秒**蒸汽、物料到出口存在显著物理传输与热质惯性                  | 窗口太短（如 10~20s）根本“看不到”造成当前波动的蒸汽/入口水分激励                 | 回看窗口锁定 `input_size = 60s`，且 TCN 膨胀率设为 `[1, 2, 4, 8]`，保证理论感受野 $> 60\text{s}$                                                                           |
| **4. 闭环 PID 反馈混叠**原始互相关可能出现符号反转（如 `1B` 的 `-0.79`）             | 黑箱模型若只拟合相关性，可能学出“加蒸汽反而降温/降水分”的伪因果，进 MPC 会发散   | 评估阶段内置**物理方向一致性检验**（对测试窗口 `steam_flow` 施加正向微扰，检查模型预测输出方向）                                                                         |
| **5. 跨天/跨月批次 + 隐藏泄露列**30s 衍生列 `col12~15` 含目标泄露和 9966 毛刺          | 随机打乱切分或全量归一化会严重高估精度                                             | 严格剔除 `col12~15`；按时间顺序**前 12 批训练 / 中 2 批验证 / 后 4 批（4 月跨月）测试**；仅在训练集 `fit` 截断阈值与 `RobustScaler`                                  |

## 二、适配的 5 类模型：选型原因与核心原理

为了形成**从简单到复杂、从线性到深度、既有工业可解释性又可对标原论文**的完整对比实验，我们在 [r4_train_and_eval.py](file:///home/atlsa/hdt_dryer_mpc/src_real/r4_train_and_eval.py) 中实现了以下 5 个递进模型：

### 1. Naive Persistence（持久性下限基线）

- **原理**：直接假设未来保持当前测量值不变：
  $$
  \hat{y}(t+h) = y(t)
  $$
- **适配原因**：工业强惯性过程（$\text{ACF}(1\text{s}) > 0.99$）的“照妖镜”。任何复杂模型如果在 `h = 30s, 60s` 处的 RMSE 无法明显低于 Naive（即 $\text{Skill} = 1 - \text{RMSE}/\text{RMSE}_{\text{naive}} > 0$），就说明模型没有学到真正的动态规律。

### 2. Multi-Output Ridge / ARX（线性自回归外生模型）

- **原理**：将过去 60 秒的关键滞后点（`-1, -6, -16, -31, -46, -60s`）与窗口统计量（均值、标准差、短/长期差分）拼成特征向量 $\mathbf{x}_t$，用带 $L_2$ 正则化的岭回归一次性映射全部多步增量：
  $$
  \min_{\mathbf{W}} \|\Delta\mathbf{Y} - \mathbf{X}\mathbf{W}\|_F^2 + \alpha \|\mathbf{W}\|_F^2
  $$
- **适配原因**：
  1. 在稳态小幅波动工况下，加料回潮的局部动力学近似线性（类似线性化 FOPDT/ARX）；
  2. 训练仅需不到 1 秒，权重直接对应各滞后通道灵敏度，**是工业线性 MPC/DMC 的直接候选模型**，也是衡量深度模型“非线性收益到底有多少”的标尺。

### 3. LightGBM（直接多步梯度提升决策树 GBDT）

- **原理**：针对每个 `(目标变量, 预测步长 h)` 单独训练一组加法决策树 $f_m(\mathbf{x}_t)$，每棵新树拟合前面所有树的负梯度（残差），以直方图分裂寻找最优非线性阈值组合。输入特征为多尺度滞后采样 + 短期/长期变化率（相当于人工构造了多尺度卷积特征）。
- **适配原因**：
  1. **抗传感器量化台阶与异常值极强**：树模型基于分位数切分，对出口含水率 `0.01%` 的台阶跳跃和局部噪声天然鲁棒；
  2. **中小规模工业数据样本效率最高**：在 12 批次（约 7,000~35,000 条滑窗样本）量级上，LightGBM 往往在 30~60s 中长步预测上表现极稳，甚至经常追平或超过未经精细调参的深度网络；
  3. 支持特征重要性分析，便于工程排查“哪些变量真正起作用”。

### 4. Residual GRU（PyTorch 残差门控循环网络）

- **原理**：GRU 通过**更新门** $z_t$ 与**重置门** $r_t$ 动态控制隐藏状态记忆：

  $$
  z_t = \sigma(W_z [h_{t-1}, x_t]), \quad r_t = \sigma(W_r [h_{t-1}, x_t])
  $$

  $$
  \tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t]), \quad h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t
  $$

  将最后一步隐藏状态 $h_T$ 经 LayerNorm 和 MLP 映射到多步残差 $\Delta\hat{y}(t+h)$。
- **适配原因**：

  1. **数学结构与一阶惯性系统高度同构**：GRU 的状态更新公式 $h_t = (1-z_t)h_{t-1} + z_t \tilde{h}_t$ 本质上就是一个**自适应时间常数的非线性一阶惯性滤波器**，天然贴合热质传递过程；
  2. 参数量比 LSTM 和 Transformer 更轻量，在 12 批次工业数据上不易过拟合，且推理延迟极低（毫秒级），非常适合在线 MPC 滚动优化。

### 5. Improved TCN-SKNet-Transformer（PyTorch 升级版混合架构）

- **原理**：将三种互补机制串联，取长补短：
  1. **因果膨胀 TCN（局部与中程多尺度时序特征提取）**：严格左侧零填充保证因果性（不偷看未来），膨胀率 `d = [1, 2, 4, 8]`、卷积核 `k = 3` 的 4 个残差块堆叠后，感受野达 **61 秒**，完整覆盖实测 32–53 秒纯滞后；
  2. **真多尺度 SK-Net（自适应通道/感受野选择）**：并行通过 `k = 3`（捕捉快速阀门/流量扰动）与 `k = 5`（捕捉较平缓温湿惯性）两个深度卷积分支，经全局平均池化与 Softmax 门控自适应加权融合；
  3. **2 层 Transformer Encoder（全局跨时间步长依赖建模）**：加上正弦位置编码，通过多头自注意力捕捉序列内任意两个时间步之间的非线性交互（例如 45 秒前的蒸汽突变与当前出口温度斜率的耦合）；
  4. **残差多步输出头 + SmoothL1（Huber）损失**：融合末尾状态与全局池化特征，同时预测未来 `[1, 15, 30, 60]s` 的增量 $\Delta y$，Huber 损失兼顾小误差的 L2 平滑性与大毛刺的 L1 抗干扰性。
- **与原资料 Keras `train.py` 的关键升级对照**：

| 对比维度              | 原资料 `transformer/train.py`                     | 本项目 `r4` 升级版（PyTorch）                                              |
| :-------------------- | :-------------------------------------------------- | :--------------------------------------------------------------------------- |
| **特征缩放**    | 全量 `MinMaxScaler.fit` 后再切分（存在数据泄露）  | 仅训练集 `fit` `[p0.1, p99.9]` 截断 + `RobustScaler`（零泄露、抗毛刺） |
| **预测任务**    | `target_time_step = 1` 单步预测绝对值（指标虚高） | 同时预测 `[1, 15, 30, 60]s` 多步**残差增量 $\Delta y$**            |
| **SK-Net 实现** | 仅做了全局池化通道注意力，无多尺度核分支            | 实现完整 Split(`k=3,5`) → Fuse → Softmax Select                          |
| **Transformer** | 传参 `num_layers=2` 但代码只写了 1 层             | 真正堆叠 2 层 `nn.TransformerEncoder` + 正弦位置编码                       |
| **训练策略**    | 固定学习率、无早停、MSE 损失                        | AdamW + CosineAnnealingLR + EarlyStopping + 梯度裁剪 + SmoothL1 损失         |

## 四、跑完后怎么看结果？（关键诊断清单）

训练结束后，打开 `outputs_real/reports/r4_train_report.txt` 和 `outputs_real/figures/` 里的 3 张图，重点看以下 4 个问题：

1. **看 `skill_vs_naive_pct`（相对 Naive 基线的提升率）**：
   - 在 `1s` 处所有模型与 Naive 差距极小属正常现象（强惯性）；
   - **真正分高下的是 `30s` 和 `60s`**——谁在 30s/60s 处 `skill_vs_naive_pct` 最高、RMSE 最低，谁就最适合做 MPC 预测模型。
2. **看 `r4_dl_loss_curves.png`（过拟合诊断）**：
   - 如果 `Train Loss` 持续下降但 `Val Loss` 很快抬头，说明深度模型记住了 3 月批次的局部噪声，可调大 `dropout`（如 `0.25`）或减小 `stride=1` 增加样本多样性。
3. **看 `r4_test_predictions_60s.png`（曲线滞后诊断）**：
   - 重点观察波峰/波谷处预测曲线是否比黑线（真实值）**右移了一段**——如果明显右移，说明模型还在偷懒依赖“最近历史 $y$”，需要强化外生特征或进一步排查滞后对齐。
4. **看报告末尾的「物理方向一致性检验」**：
   - 若增加蒸汽后模型预测出口水分/温度反而下降，说明闭环 PID 伪相关影响了模型因果方向，下一步需引入**物理约束损失（PINN/单调性正则）**或采用 **ARX/FOPDT 机理 + 残差神经网络混合建模**。
